## 这里写什么

游戏、科技，以及它们与日常生活发生联系的地方。

这里有对游戏体验的具体讨论，也有对游戏行业、科技数码、AI 与企业变化的观察。游戏摄影、模拟驾驶、跑鞋和厨艺，同样在我的兴趣范围之内。

我喜欢从一个具体的问题出发，把体验、事实和判断慢慢说清楚。一款游戏哪里好玩，一项技术改变了什么，一门生意为什么走到今天，往往都值得多花一点篇幅。这个博客用来保存这些文章，也留下一些当时的看法，供日后回看。

## 这个站点如何搭建

- **后端**：使用 [NotionNext](https://github.com/notionnext-org/NotionNext)。
- **前端、部署方案与功能实现**：由我与 ChatGPT 协作完成。
- **静态托管**：使用 GitHub Pages。

本仓库保存 Insignificantia. 的站点源码。文章阅读与作品浏览，请访问[博客](https://takedaiori.github.io/)。
