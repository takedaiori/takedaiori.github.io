# 暂留资源安全复核与裁剪关闭

2026-11-02。范围为 docs/maintenance/pruning-candidates.md 的全部组别。按照所有者要求保留功能，修复安全问题后关闭裁剪事项，不继续安排删除。这里记录源码和可运行测试的结论，不表示未连接的 Netlify、数据库或其他账户后台已核验。

| 组别 | 安全判断与处理 |
| --- | --- |
| 搜索、归档、错误页、会员及授权静态路由、页面元数据 | 大体积主要是性能问题。静态 Pages 无法执行服务端认证；公开导出的文章、摘要和隐藏链接不能当作秘密。现有写接口默认关闭、缓存/刷新鉴权和旧授权拒绝行为继续保留；没有为瘦身重新开放接口。 |
| Clerk、Supabase、Redis、Vercel 缓存、搜索、评论、订阅、Facebook 等备用集成 | 留在源码不等于启用服务，私密权限取决于运行环境和账户策略。保持原有默认关闭、服务端凭据隔离与发布产物扫描；依赖仍纳入全锁文件审计。不能以当前静态部署推定未来服务器的外部数据库权限正确。 |
| Cusdis 本地备用脚本 | 修复 srcdoc 配置串可提前关闭 script 标签、缺少消息来源验证的问题。JSON 中的 < 转义；属性转义；主机须 HTTPS、脚本须同源；iframe 使用无 same-origin 权限的 sandbox；只接受该 iframe 消息，尺寸限有限数字 0–20000。默认仍不启用评论。 |
| Giscus 本地脚本 | 在已有 giscus.app origin 检查上增加精确 iframe source 检查；不接受其他同域窗口冒充。 |
| AOS、Lenis、Typed、WOW 与背景/鼠标特效 | 复核加载入口与本地脚本；没有发现新增的任意代码执行或凭据发送路径。原有固定版本、完整性记录、外部脚本加载策略及扫描保留；AOS 无可靠版本标记，新增按全版本查询，并为另外 17 份本地脚本/样式/manifest/sw.js 保存人工复核后的 SHA-256。这 17 份的完整性检查不冒充 npm 漏洞数据库覆盖。动画性能成本不等同于安全漏洞；无“永久无风险”保证。 |
| 自定义资源、剧透与正文样式 | custom.js 当前仅注释；样式及本地 SVG 检查未发现执行型载荷。剧透脚本处理站长控制的正文 DOM，不接受访客评论作为文章内容；不为其开放任意配置 JS。 |
| 徽章、图标、默认图、Hero/About 图、manifest 与 sw.js | 静态资源本身未发现执行载荷。sw.js 没有实现请求缓存或跨站代理，只清理本站特定前缀的旧缓存；保留图片包校验与解码限制。 |
| 图片代理 Worker | 6 项现有安全测试通过：大小、类型、凭据隔离、错误不缓存、SVG 响应隔离、限流失败关闭。部署配置中的上游作者域名改为 cdn.example.invalid；没有部署 Worker，也没有连接外部账户。 |
| 旧迁移/搜索提交/维护工作流 | 保持仓库限定和停用条件。pushUrl.py 中全局关闭证书验证与 HTTP 令牌发送有潜在风险，已移除不安全 TLS 设置、改 HTTPS、限制网络超时并避免异常日志输出含令牌 URL。未恢复自动推送。 |
| 构建、类型、CSS 和测试工具 | 保留必需质量工具，继续按完整依赖树扫描。deepmerge/minimatch 的具体公告、适用条件和兼容性见 [工具链公告处理](toolchain-advisory-mitigations.md)；不会以删除测试工具或忽略公告来伪造清零。 |

## 验证

安全边界静态检查、Worker 6 项测试、Cusdis 恶意配置/伪造消息/不安全主机回归测试、CodeQL 门禁回归测试均在本地运行。合并前还需以当前提交的必需 CI、两种语言 CodeQL、完整导出与实际浏览器/服务器检查结果为准。

## 关闭边界

裁剪项目关闭，清单仅保留历史用途。依赖漏洞修复和安全维护继续；不审计已取消的 Netlify 后台，不修改所有者要求跳过的旧式分支保护。以后启用某个外部服务时仍需按实际服务配置校验权限与密钥，不能把“暂未使用”当成账户审计结论。
