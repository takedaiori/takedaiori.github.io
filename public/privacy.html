适用范围与联系

本说明适用于 Insignificantia. 个人博客，作者为竹田伊織（takedaiori）。隐私问题可通过 About 页列出的公开社交渠道联系作者。请勿通过公开仓库 Issue 提交密码、密钥、身份证件或其他敏感资料。

网站托管与资源请求

本站由 GitHub Pages 托管。浏览器获取页面、图片或脚本时，会向对应服务发送网络请求，涉及 IP 地址、请求时间及浏览器发送的技术信息。托管和资源服务商根据其政策处理这些信息。本站不能承诺所有服务均不处理 IP 地址或不保存日志。

Cloudflare Web Analytics

本站加载 Cloudflare Web Analytics，用于了解页面访问与加载性能。浏览器会向 Cloudflare 请求统计脚本并发送性能与访问统计。Cloudflare 对该产品的说明称其不收集或使用访客个人数据，也不跨客户网站跟踪个人用户。作者使用其提供的统计结果，不将网页中的公开统计标识作为账户密钥。

兼容访问计数

站点程序另保留不蒜子兼容计数功能；启用时默认连接 Vercount（events.vercount.one），提交页面地址和是否首次访问的标记。本站的默认 Vercount 请求只发送网站源与路径，不发送地址查询参数或片段，并不携带跨站 Cookie。它可能在本站设置最长一年有效的 vercount_uv_ 前缀 Cookie，用于区分首次访问；该 Cookie 可由浏览器清除或阻止。此说明不将该服务的数据保留方式等同于 Cloudflare 的政策。

浏览器本地存储

页面使用 localStorage 或 sessionStorage 保存外观、Design Guide 语言、导航过渡和图片展示状态。语言或外观偏好可持续保留至被覆盖或由你清除；会话状态通常随对应浏览器会话结束清除。浏览器设置可以清除本站 Cookie 与网站数据，清除后部分偏好或首次访问状态会重置。

文章嵌入、外部资源与链接

文章可能加载 Notion 或对象存储中的图片，以及第三方媒体或其他资源；部分页面也可能引用外部资源服务。加载嵌入内容或访问外链时，相关服务可能接收网络技术信息，并适用其自己的隐私政策。请勿在网址参数或公开留言中放入敏感信息。

联系信息、保留与请求

你通过社交平台联系作者时，平台按自身政策处理信息，作者仅应接收处理沟通所需的内容。你可通过同一渠道提出查阅、更正或删除作者持有的相关沟通资料的请求；需要保留的信息按适用法律和处理目的判断。托管商及第三方服务的日志和保留规则由相应服务商管理，本说明不替其承诺删除时限。
